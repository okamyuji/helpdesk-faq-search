# 0006 使わない期間はRDSを削除し、予算の通知を入れる

状態 承認

## 状況

検証環境は毎日は使いません。RDSは止めても7日たつと[自動的に起動し直し](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_StopInstance.html)、止めている間もストレージの料金がかかります。

## 決定

作業を終えるたびに、サービスのタスク数を0にし、RDSは最終スナップショットを取ってから削除します。再開するときは、スナップショットから戻します。スナップショットは直前の1つだけを残します。

AWS Budgetsで月の予算を作り、`Project`タグで絞ります。実績が予算の80%と100%を超えたときと、予測が100%を超えたときに、メールで知らせます。通知は、Terraformの変数`budget_emails`に宛先を渡したときだけ作られます。

## 影響

- RDSの停止は使いません。
- 再開のたびに、スナップショットからの復元の時間がかかります。
- タグで予算を絞るには`Project`タグを費用配分タグとして有効にしておく必要があります。
