# 0001 検証データに官公庁のよくある質問を使う

状態 承認

## 状況

社内ヘルプデスクのように、質問と回答を蓄積して探す仕組みで検索の質を測りたいと考えました。学校の問い合わせ窓口のような場面でも、同じ仕組みを使えます。実際の問い合わせ履歴は個人情報や社外秘を含むので、公開する検証には使えません。

## 決定

[JaGovFaqs-22k](https://huggingface.co/datasets/matsuxr/JaGovFaqs-22k)を使います。このデータは官公庁のWebサイトに掲載された「よくある質問」を質問と回答の組にまとめたもので、約2.2万件あります。ライセンスはCC BY 4.0で、著作権者は各官公庁です。

## 影響

- 出典を示せば、回答の文章を画面と文書に載せられます。画面と文書には出典の官公庁名と元のURLを必ず表示します。
- データはリポジトリに入れず、取得の手順だけを書きます。データの更新に追従しやすくするためです。
- このデータは日本語の埋め込みモデルの評価（JMTEB）にも使われています。モデルが似た文章で学習している可能性があるので、検索の質の数字は実際の問い合わせ履歴より高めに出ることがあります。
- 公務員が確認した文章なので、回答の側の表記ゆれは多くありません。表記ゆれの比較では利用者が入力する検索語の側のゆれが中心になります。
