# 0012 ベクトル検索で候補を集め、BedrockのCohere Rerank 3.5で並べ替える

状態 承認

## 状況

社内ヘルプデスクの検索で大事なのは、問い合わせに答える1件の質問と回答の組を上位に出すことです。利用者は、よくある質問の質問文とは違う言い方で問い合わせます。

JaGovFaqs-22kから無作為に選んだ100件について、元の質問文を見せずに言い換えた問い合わせを2種類作り、元の組が何位に出るかを測りました。言い換えはAIで作り、元の質問と8文字以上一致する部分がないことを確かめています。2種類は、口語の質問と、2〜3語を空白で区切った短い検索語です。上位1件の正解率（Recall@1）は次のとおりでした。

| 方式 | 口語の質問 | 短い検索語 |
|---|---|---|
| キーワード検索（pg_bigmと同じ部分一致） | 0.00 | 0.35 |
| pg_trgm | 0.07 | 0.06 |
| ベクトル検索（Ruri v3-30m） | 0.73 | 0.66 |
| ベクトル検索（Ruri v3-310m） | 0.79 | 0.72 |
| キーワード検索の結果を先頭に置き、不足をベクトル検索（310m）で補う | 0.78 | 0.35 |
| キーワード検索とベクトル検索（30m）をRRFで統合 | 0.74 | 0.60 |
| キーワード検索とベクトル検索（310m）をRRFで統合 | 0.79 | 0.57 |
| ベクトル検索（30m）の上位30件を`ruri-v3-reranker-310m`で並べ替え | 0.85 | 0.71 |
| ベクトル検索（310m）の上位30件を`ruri-v3-reranker-310m`で並べ替え | 0.85 | 0.67 |

キーワード検索の結果を先頭に置く方式では、短い検索語に一致する多数の組が上位を埋め、正解を押し出しました。RRFもキーワード検索の結果に引きずられ、短い検索語で正解率が下がっています。

## 決定

既定の検索は次の手順にします。

1. 問い合わせの埋め込みをRuri v3-30mで計算し、ベクトル検索で上位30件を集める。
2. Amazon BedrockのCohere Rerank 3.5（`cohere.rerank-v3-5:0`）で30件を並べ替え、上位10件を表示する。

並べ替えのモデルは、次の計測で選びました。候補は3つとも同じ「30mのベクトル検索の上位30件」です。

| 並べ替えのモデル | 口語の質問 Recall@1 | 短い検索語 Recall@1 | 1回の応答 p50 | 1回の応答 p95 |
|---|---|---|---|---|
| `ruri-v3-reranker-310m`（TEI、CPU） | 0.85 | 0.71 | 20.3秒 | 26.6秒 |
| Amazon Rerank 1.0（Bedrock） | 0.81 | 0.70 | 0.56秒 | 2.16秒 |
| Cohere Rerank 3.5（Bedrock） | 0.83 | 0.77 | 0.20秒 | 0.34秒 |

`ruri-v3-reranker-310m`の精度は、Apple SiliconのMPSで計算したものです。TEIでのCPUの応答時間は、実際のFAQの全文30件をColimaの4 CPUで並べ替えて測りました。候補を10件に減らし、文を300字に切っても4.2秒かかりました。準備中の最大メモリも6.16GiBありました。このときTEIは`onnx/model.onnx`がないためONNXの実行方式を使えず、candleの実装で動いていました。ONNXに変換した場合とFargateでの時間は測っていません。

LLMによる選び直しは入れません。理由は[0011](0011-haiku-selection.md)のとおりです。

キーワード検索とRRFは、比較のための切り替えとして画面に残します。

## 影響

- 埋め込みは30mで足りるので、取り込みの計算は310mの約12分の1の時間で済みます（Apple SiliconのMPSで1秒あたり513.4件と43.1件）。
- 並べ替えの費用は、東京リージョンで検索単位1つあたり0.002ドルです（AWSの料金API）。候補30件の並べ替え1回が1検索単位なら、1,000回の検索で約2ドルです。
- このアカウントの東京リージョンでは、Cohere Rerank 3.5の呼び出しは1分あたり25回が上限です。検索1回で1回呼ぶので、1分あたり25検索が上限になります。足りなければService Quotasで引き上げを申請します。
- 問い合わせの文と候補の文は、Bedrockの東京リージョンに送られます。
- Cohere Rerank 3.5はAWS Marketplaceの製品で、最初に呼んだときに契約が作られます。固定の費用はなく、呼んだ分だけ課金されます。
- Bedrockの呼び出しが失敗したときは、ベクトル検索の順位をそのまま表示します。
- この計測の言い換えは100件で、AIが作ったものです。実際の問い合わせの言い方とは違いがありえます。
