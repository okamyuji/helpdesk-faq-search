# 0009 照合の前に文字をNFKCで正規化する

状態 承認

## 状況

日本語の文章では全角と半角の英数字や記号が混在します。正規化しないと「PC」で検索したときに「ＰＣ」と書かれた文書を部分一致で見つけられません。

## 決定

部分一致で照合する文字列は文書も検索語もUnicodeのNFKCで正規化します。文書は正規化した文字列を別の列に持ち、その列にpg_bigmの索引を作ります。Goでは`golang.org/x/text/unicode/norm`の`NFKC`を使います。

## 影響

- 埋め込みの計算には正規化する前の文字列を使います。
- 画面に表示する文字列も、正規化する前のものです。
