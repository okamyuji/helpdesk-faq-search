# 0007 LLMで回答文を作る仕組み（RAG）は入れない

状態 承認

## 状況

問い合わせ窓口では検索で見つけた文書をLLMに渡して回答文を作らせる仕組み（RAG）も考えられます。RAGを入れると検索のたびのLLMの費用、根拠にない内容を回答に書く誤りへの対策、回答の正しさの評価が必要になります。

## 決定

RAGは入れず、検索だけを作ります。よくある質問の回答文はすでに人の手で整えられているので、正しい質問と回答の組を上位に出せれば、その回答を見せるだけで多くの問い合わせに答えられます。

## 影響

- 回答が複数のよくある質問にまたがる問い合わせでは、利用者が複数の結果を読む必要があります。
- RAGを足す場合でも回答の質は検索の質で決まります。この検証の結果はRAGの前段を選ぶ判断にも使えます。
