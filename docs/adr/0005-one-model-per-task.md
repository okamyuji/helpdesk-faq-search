# 0005 埋め込みモデルはタスクの定義で切り替える

状態 承認

## 状況

Ruri v3の30m、130m、310mの3つのモデルで、検索の質と費用を比べたいと考えました。TEIは1つのプロセスで1つのモデルしか動かせません。

## 決定

1つのタスクで動かす埋め込みモデルは1つにします。並べ替えのモデルはBedrockのCohere Rerank 3.5に固定します（[0012](0012-ranking.md)）。モデルはTerraformの変数で選び、モデルを替えるときはタスクの定義を更新します。DBには3つのモデルの埋め込みを並べて保存できる形をとります。

## 影響

- 画面ではモデルを選べないので、動作中のモデル名だけを表示します。
- 取り込み、評価、応答時間の計測は、モデルを切り替えながら3回行います。
- モデルごとの費用を分けて測れます。
