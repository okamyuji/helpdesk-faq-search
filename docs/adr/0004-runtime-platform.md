# 0004 ECS Fargateの1タスクにアプリとTEIを同居させる

状態 承認

## 状況

検索の質に加えて、本番に近い形で運用の費用を測りたいと考えました。検証用の画面は自分だけが開ければ足ります。

## 決定

Amazon ECS on Fargateで、アプリと埋め込み用のTEIの2つのコンテナを1つのタスクで動かします。アプリはTEIを`localhost`で呼びます。並べ替えはAmazon Bedrockを呼びます（[0012](0012-ranking.md)）。ロードバランサーは置かず、ECS Execのポート転送で画面を開きます。タスクのセキュリティグループには受信のルールを置きません。

## 検討した選択肢

- EC2 1台でdocker composeを動かす 最も単純で安い方法ですが、本番の形と違うので、運用の費用の参考になりにくくなります。
- アプリをLambda、TEIをFargateで動かす アプリ側は安くなります。ただしTEIは常時起動が必要で、全体の費用は変わらず、構成要素が増えます。

## 影響

- 使わない時間はサービスのタスク数を0にできます。
- タスクには公開IPを付け、ECRからの取得とSSMへの接続に使います。NATゲートウェイは置きません。
